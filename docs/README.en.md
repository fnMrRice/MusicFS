# MusicFS

[简体中文](../README.md) · English

MusicFS is a self-hosted music library. Add a music folder to your server, then browse and play your collection by track, artist or album in a browser. You can organize playlists and fill in missing lyrics, covers and tracklists.

![The MusicFS Web track list with a track playing](screenshots/web-library.png)

*Screenshot of the Web library with demo tracks and artwork.*

## Features

- **Organize music files.** Scan local directories or mounted network shares and read tags, embedded artwork and lyrics stored alongside your music. Group multiple source files for the same track while keeping the original files in place.
- **Fill in album details.** Find releases by name, ID or album link. Preview the tracklist, artwork and other fields before choosing what to save. [Metadata plugins and data sources](https://github.com/fnMrRice/MusicFS-server/blob/main/docs/plugins/provider-api-sources.md)
- **Play music and manage playlists.** Stream compatible audio directly to your browser or let the server convert it with FFmpeg. Online sources vary by platform. For example, you can import public Bilibili favorites and play available audio tracks. [Online sources](https://github.com/fnMrRice/MusicFS-server/blob/main/docs/providers/online.md)

## Run from source

Building the Web client and server requires Git LFS, Go, Node.js and npm. See the [build guide](packaging.md) for tool versions and options.

```sh
git lfs install
git clone --recurse-submodules https://github.com/fnMrRice/MusicFS.git
cd MusicFS
```

From the root of the repository, run both commands for your platform.

| Platform | Build | Start |
| --- | --- | --- |
| Windows x64 (PowerShell) | `./scripts/package.ps1` | `./deploy/musicfs-windows-amd64/start.bat` |
| Linux x64 (Shell) | `sh scripts/package.sh` | `sh deploy/musicfs-linux-amd64/start.sh` |

Open <http://127.0.0.1:8080> and sign in with the administrator token generated by the launcher. Under **设置 → 音乐源 → 本地音乐 → 添加本地目录** (Settings → Music sources → Local music → Add local directory), choose a folder the server can read. Saving starts a scan. When it finishes, open the track list to play your music. [First sign-in, directory access and audio tools](packaging-start.md)

| [MusicFS-web](https://github.com/fnMrRice/MusicFS-web) | Browser library, player, playlists and administration |
