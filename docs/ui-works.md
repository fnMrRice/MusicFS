# 作品库与类型详情页设计

状态：2026-10-22。作品列表、手工资料创建／编辑、本地作品包导入、目录树、文件音轨播放及附件已接入。多碟发行、CUE 分段、作品封面与续听仍为目标设计。线框展示目标结构，不表示其中所有控件已可用。

## 1. 信息架构

左侧统一使用可折叠的“作品库”分组，沿用现有顶部工具栏和底部播放器。首次使用默认收起，展开状态随当前账号及服务实例保存在本机 localStorage；刷新或重新打开后恢复上次状态。箭头仅展开／收起，点击“作品库”文字进入全部作品并展开子项。

| 入口 | 内容 |
| --- | --- |
| 作品库 | 父入口，显示全部已建档作品 |
| 作品库 → 曲目列表 | 搜索、筛选和播放普通音乐来源音轨，排除 ASMR 作品与 CD 抓轨副本 |
| 作品库 → 专辑 | `music` 类型作品，包含专辑、EP 与单曲发行 |
| 作品库 → ASMR | `asmr` 类型作品 |
| 作品库 → CD 抓轨 | 至少持有一份明确标记为 CD 抓轨的本地副本的作品 |
| 搜索、推荐、歌单 | 保留各自语义；不会把作品自动转成歌单 |
| 设置中的来源管理 | 继续管理授权目录和来源实例；内容类型不是 Provider |

页面顶部不再重复显示分类按钮。侧栏内容分类由 Server 注册声明生成，其中 `music/asmr` 使用简短名称“专辑／ASMR”，新增类型也能显示；编辑器保留插件完整名称及说明。“CD 抓轨”按本地副本类型筛选，不新增互斥的内容类型，同一作品可以同时属于专辑或 ASMR 分类以及 CD 抓轨视图；普通 FLAC 或带 CUE 的目录不会被自动推定为抓轨。音乐作品的多发行关系仍待实现。

当前分类按路径与查询参数精确高亮，不让所有 `/works` 子项同时选中。收起时父行仍提示当前页面属于作品库。窄屏保留子项的小字号文字，展开后均可访问；切换分类、折叠和刷新列表不会停止播放。

当前路由为 `/works`、`/works/:id`。详情页分为阅读和编辑状态，避免将管理表单直接当作日常浏览页面。前往作品、返回列表和切换类型都不停止已有播放。

## 2. 作品列表

顺序为当前分类标题与创建操作、关键词及标签过滤、作品卡片、分页。宽屏使用自适应网格，窄屏减少列数，表单和操作换行。关键词、标签及翻页请求保留当前内容类型和副本类型条件。

卡片突出标题、内容类型、主要参与者和标签；有真实封面能力后再加入封面。没有封面时不生成伪造图片；没有已验证音轨或总时长时不显示虚假数量和播放按钮。关键词匹配标题、简介、编号和署名；类型与标签条件取交集。

切换筛选从第一页重新请求，忽略旧请求返回；下页追加按稳定作品 ID 去重。当前 API 为实时 ID 游标分页，不承诺固定快照或总数量，也不以已加载条数冒充全部。空库与筛选无结果使用不同文案，读取失败提供重试。

目标线框：[作品列表](prototypes/work-library.salt.puml)。

## 3. 音乐详情目标

上方展示标题、主要参与者、发行资料与封面。中部先选发行版本／本地副本，再按碟片展开音轨。音轨包含碟号、轨号、标题、时长和实际可用来源；整轨+CUE与逐轨文件使用相同的逻辑音轨展示。

同一作品的重制版、不同录音与纯编码副本分别标示。播放全部只作用于当前选定发行／分组；不能把所有编码副本重复入队。附件区提供真实存在的内页、歌词和日志。

目标线框：[音乐多碟详情](prototypes/work-music.salt.puml)。当前音乐作品先复用本地包树和完整文件音轨，CD1／CD2 保留为原目录；发行选择和 CUE 逻辑音轨仍未实现。

## 4. ASMR 详情目标

上方展示标题、作品编号、社团、声优及标签，简介独立成区；其他署名可展开。随后选择本地作品包与内容分组，保留包内目录树，音轨和附件明确区分。

WAV／MP3 文件夹先保留真实结构，只有明确建立格式关系后才作为可选来源呈现。有BGM／无BGM等内容分组由识别方案或用户确认，播放前明确选定，不默认合并全部分组。将来续听展示确切音轨及位置；包离线时保留资料和进度。

目标线框：[ASMR 作品详情](prototypes/work-asmr.salt.puml)。

## 5. 当前可用的详情与导入

详情页包含标题与类型、简介、按插件角色标注的参与者、外部编号、标签和编辑操作。资料下方展示本地作品包选择、可折叠目录树、音轨和附件。未知／未注册类型仍显示保存的资料和已有包，并明确当前不能编辑或导入。刮削、作品收藏、作品封面及续听尚未接入。

“导入本地副本”选择普通目录或 CD 抓轨，再选择来源、授权根、文件夹，显示完整树及目录／音轨／附件数量，确认后保存。没有可用本地来源时提示先配置来源；不让用户输入服务器绝对路径。预览不发布曲目，确认后才连接统一播放链。再次选择相同位置更新原副本，也可调整副本类型；原始文件变化时提示重新预览。CD 抓轨视图中新建作品后直接进入抓轨导入，已有作品可在详情中导入或重新标记副本。

目录可展开／收起，空目录也保留。音轨提供播放与加入队列，目录操作只作用于该目录下的可用音轨；包内存在多个格式副本时由用户选择目标目录，不推断等价关系。当前资产不再匹配的节点保留文件名并禁用播放。

附件提供受控预览及原件下载。PNG／JPEG／GIF 图片和 UTF-8 文本可预览，文本按纯文本显示；PDF、SVG、WebP、未知编码等保留下载。图片仅作包附件展示，不自动成为作品封面。附件被替换或来源不可用时显示错误，不使用新文件冒充原版本。

创建时选择内容类型；之后类型不可直接更改。编辑支持增加／移除参与者与编号，并使用插件声明的选项。没有某类角色或编号声明时隐藏新增入口，不丢弃已有未知资料。

保存使用服务端修订和幂等键。网络中断、超时或响应异常导致结果不明时，锁住当前参数并保留原键，先重试确认原操作；不能直接修改后换键新建另一份作品。收到明确的未写入错误后才允许调整内容并使用新键。修订冲突保留当前输入并提示刷新最新资料后重新编辑，不偷偷覆盖其他端修改。离开页面后，旧写入请求完成不触发跳转或更新已卸载的界面。按钮具有明确忙碌状态，错误可见且可恢复。

## 6. 扩展与验收

视图声明只引用宿主已支持的组件模板。当前为通用 `work-list`／`work-detail`，详情中包含可复用作品包组件；音乐发行／碟片列表和续听组件仍待后续接入，不以声明存在代表前端功能已经交付。

验收覆盖声明驱动的类型与角色、不同类型切换、中文资料创建／读取／编辑、筛选与分页、失败重试、修订冲突、未知类型只读、窄屏与键盘可用性。作品包另用真实 Server 和音频文件验证导入、播放、附件、重导入及重启持久化；CUE 分段收听需等待对应播放能力。
