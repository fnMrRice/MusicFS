# 本地音频作品库与内容插件扩展

更新于 2026-11-14。本文定义作品和普通音乐的浏览范围、内容插件及本地作品包的共同语义。交付阶段见第 7 节。

## 1. 目标与范围

曲目列表管理普通音乐，CD 专辑、ASMR 和电台分别作为内容插件提供独立作品库，复用来源音轨身份、文件授权和播放链。作品包的输入是 Server 可访问的本地文件，包括抓轨结果、音声作品包和电台节目录音。

优先覆盖：

- 音乐专辑、多碟目录、逐轨音频、整轨音频与 CUE、封面及内页资料。
- ASMR 作品编号、社团／声优、作品包、多层目录、内容变体及附带图片、文本和字幕。
- 电台作品资料、本地节目音频及附件。在线直播与节目订阅需要独立的来源和播放能力。
- 通用作品检索、人工资料编辑、收藏、进度和书签。

广播剧和有声书作为后续内容类型；播客另需订阅、更新和下载机制，不纳入第一轮。ASMR 与广播剧等标签允许交叉，内容类型决定管理模板，不应成为互斥题材分类。

## 2. 数据语义

| 概念 | 语义 |
| --- | --- |
| 作品 | 稳定的管理条目，带内容类型、标题、简介、外部编号、参与者及标签 |
| 外部编号 | 来源命名空间与值；RJ 等编号不是数据库主键，没有编号也能建档；相同编号只产生关联依据，不自动合并 |
| 参与者 | 名称与明确角色，允许多名声优、社团、脚本及插画署名；精确署名不等于已验证的真人身份 |
| 发行 | 特定出版或发布版本；CD 是载体资料，重制版等内容差异与文件编码分别记录 |
| 碟片／分组 | 作品内部的有序结构，可表达 CD1/CD2、正篇／特典；不直接等同于内容变体 |
| 本地作品包 | 作品在一个来源中的持有副本，记录授权根、位置、文件集合和可用性；同作品可有多份包 |
| 包节点 | 保留包内目录树及显示顺序，指向音频或附件；移动文件尽量保留稳定关系 |
| 逻辑音轨 | 用户选择的播放单元，可以对应完整音频文件或文件内的时间段 |
| 来源与资产 | 继续由 SourceTrack／SourceAsset 表达来源身份和固定文件版本；与作品、逻辑音轨的关系单独保存 |
| 附件 | 作品、包或音轨上的图片、说明、脚本、字幕、CUE、抓轨日志等；时序字幕绑定具体音频版本 |
| 收听状态 | 按用户保存作品收藏、完成状态、上次音轨及位置、书签 |

现有 SourceAlbum／Release 是显式有序集合，不能仅改名即视为完整作品模型。现有 Recording 仍表示同一录音，不用于包裹一部作品的全部章节。基础模型只提取上述已知需求，不建设任意实体的动态数据库。

### 2.1 内容、载体和文件形式

内容类型（音乐／ASMR 等）、发行载体（CD／数字发行）、内容结构（多碟／章节／特典）和本地保存形式（逐轨 FLAC／整轨 FLAC+CUE）是不同维度。WAV／MP3 目录可能是格式副本，有背景音乐／无背景音乐可能是内容变体；先原样保留，不仅凭目录名建立等价关系。

作品归入创建时选择的内容类型，CD 专辑（`cd_album`）、ASMR（`asmr`）和电台（`radio`）分别浏览。本地副本仍可标记为普通目录（`directory`）或抓轨文件（`cd_dump`）。同一 ASMR 作品的逐轨 CD 副本仍归 ASMR。升级时，旧 `music` 作品中持有抓轨副本的条目转入 CD 专辑；其他既有音乐资料保留原身份。

CD 专辑可按作品保存 `showInTrackList`，默认关闭。开启后，该专辑已确认导入的音轨同时出现在普通曲目列表与 CD 详情，沿用原有来源 ID。ASMR、电台及未开启展示的 CD 专辑只在各自作品库浏览。音乐的专辑、歌手、流派、目录、筛选计数和播放全部使用相同的可见成员。展示开关仅改变新查询的范围，已保存的歌单和播放引用继续使用原身份。

### 2.2 CUE 与播放身份

CUE 导入建立逻辑音轨和文件时间范围，默认不切割原文件。解析保留每秒 75 帧的精确位置；多 FILE 各有独立时间轴。末轨结束位置必须等待实际音频探测，不能猜测文件时长。间隙处理规则必须在解析与播放合同中明确。

后续分段播放必须将逻辑音轨、文件资产版本、区间和输出表示共同绑定；对外进度从该逻辑音轨的零点计算，定位与结束不能越界，续播不能沿用已变化的资产或区间。仅完成 CUE 文本解析不代表已提供分段播放或无缝播放。

## 3. 插件扩展点

| 扩展点 | 插件输出 | 宿主责任 |
| --- | --- | --- |
| 内容类型注册 | 类型与发行身份、名称、字段、参与者角色、编号命名空间、视图声明 | 注册和冲突校验、查询能力、不可变声明、客户端能力展示 |
| 作品包识别 | 包边界、编号候选、节点、分组、音轨顺序及歧义 | 提供授权快照、预览和人工修正、完整发布与稳定身份 |
| 逻辑音轨解析 | CUE 等格式的结构与相对文件引用、时间范围 | 文件授权解析、实际版本和时长验证、音轨身份与播放 |
| 作品级刮削 | 作品资料候选、来源和依据 | 目标修订、预览、人工锁、候选选用、媒体发布 |
| 作品与版本匹配 | 关联建议、内容差异与格式副本证据 | 人工确认、排除、关联／解除与审计；不代替 Recording 匹配 |
| 作品界面声明 | 支持的列表／详情模板、字段、筛选和受控动作 | Web／Client 通用组件、会话与命令授权；不执行任意脚本 |

Local Files 扩展为提供作品包所需的目录与非音频观测；文件访问仍由 Provider 与宿主授权。ASMR 插件负责 RJ、社团、声优和包组织规则。不同资料来源使用独立 Scraper。数据库后端维护具体 SQL、索引和迁移，普通内容插件无任意 SQL 或核心库访问权。

内容插件通过 `sdk/contenttype` 声明参与者角色、编号命名空间和宿主视图。可选的 `library` 声明提供导航顺序、图标与可选曲目展示能力。Web 将这些入口排在固定的曲目列表之后。CD 专辑、ASMR 和电台随 Server 构建并注册；普通音乐继续使用宿主的曲目列表。

作品包增量提供 `PackageOrganizer`。宿主交付授权快照的路径及节点种类，插件返回完整显示顺序。内置类型保留原目录并按数字自然排序。文件授权、包边界与发布仍归宿主管理。

## 4. 导入与编辑流程

1. 管理员添加本地目录并选择内容类型，类型选择不扩大目录权限。
2. 文件来源产生固定扫描范围内的目录、音频和附件快照。
3. 内容插件生成导入方案；不明确的包边界、版本或关联保留待确认状态。
4. 宿主校验资源、所有者、代次和修订，再整体保存；失败或不完整扫描保留旧内容。
5. 作品级 Scraper 提供可预览的候选资料，人工资料和锁不被扫描覆盖。
6. 客户端按类型模板展示作品；选择具体音轨／版本后使用统一播放链。

手工建档先独立可用，不要求扫描、外部编号或在线刮削成功。当前可在已建档作品详情选择本人可用的本地来源、授权根及作品文件夹，预览完整树后确认导入。音频复用 Local Files 身份和播放链；图片、文本及其他附件保存版本化文件引用。再次选择同一位置会更新已有包，不创建重复副本，不修改手工作品资料。

导入保留空目录及 WAV／MP3、正篇／特典等原始分组。用户明确选择音轨或目录后播放，不自动把全部格式副本入队。预览后文件、来源配置或作品修订变化会拒绝确认；部分遍历失败不会发布残缺包。当前必须手动重新导入才能更新目录树，没有自动包发现、树编辑或作品包监听同步。

## 5. 生命周期与存储

登录权限、稳定身份、事务、修订、幂等、文件保护和最终发布由宿主负责。收藏、进度和作品资料是业务数据，不放在只适合小状态的插件私有缓存中。

未来停用内容插件后停止新的专属识别与资料写入，但已有数据可由通用页面读取，音频仍经公共播放链访问。第一批内置类型随 Server 装配，没有可操作的内容插件停用开关；不得展示虚假的动态安装／启停能力。

官方实现继续随 Server 构建，在主进程运行。新增类型需要注册、配套构建与验证，不等同于运行时下载任意插件。数据库结构变更用 SQL 迁移，不在业务代码中添加旧结构兼容分支。

## 6. 仓库分工

- 本仓库：本文、总体架构入口与 [PlantUML 扩展图](diagrams/content-library.puml)。
- Server：内容 SDK、内置类型、作品 API／Schema、数据模型、SQLite 迁移、扫描／解析／播放适配。
- Web：作品列表与编辑／详情组件、插件声明驱动的角色和编号选择。
- 共享页面结构见[作品库与类型详情页设计](ui-works.md)，音乐多碟和 ASMR 包树采用不同的详情模块；现有曲目列表继续作为直接找音频的入口。
- Client：后续复用协议及可用展示语义；当前增量不代表桌面实现完成。

## 7. 阶段与验收

| 阶段 | 内容 | 验收 | 当前状态 |
| --- | --- | --- | --- |
| L0 | 内容类型 SDK、CD 专辑／ASMR／电台声明与普通曲目展示策略 | 校验声明、隔离各库、切换 CD 曲目的可见性 | 已接入 Server 与 Web |
| L1 | 作品资料建档、编辑、检索、Web 入口 | 持久化、账号隔离、幂等、旧修订冲突、分页与中文资料 | 已完成当前范围 |
| L2 | CUE 纯解析 | 多 FILE、精确帧、异常结构、路径边界；无文件访问 | 已完成当前范围 |
| L3 | 完整包扫描、附件、导入预览与人工纠正 | 多层目录、文件移动、部分扫描、图片／文本附件 | 已完成手动选包、完整预览／确认、重导入、详情树、音轨播放与附件；自动发现／同步、移动包根定位与树编辑待实施 |
| L4 | 多碟发行、逻辑音轨持久化与 CUE 播放 | 实际音频范围、间隙、末轨、定位、队列与资产变化 | 待实施 |
| L5 | 作品收藏、续听与书签 | 按用户隔离，恢复绑定稳定音轨和资产证据 | 待实施 |
| L6 | 作品级在线刮削、匹配增强 | 按资料来源验证字段、保护人工选择 | 已接入 Server/Web 的按字段搜索、预览与人工选用；自动作品关联及排除规则待实施 |

作品详情可按字段保存专辑曲序、作品与歌手资料、图像等在线候选，保留来源编号与页面。曲目入口可选用在线歌词和封面。各来源的能力和配置见 [Server 在线资料插件](../server/docs/metadata/online-scrapers.md)。

交付记录与精确 API 见 [Server 作品资料](../server/docs/library/works.md)和[本地作品包](../server/docs/library/work-packages.md)。以测试与实际运行证据推进状态，不以目录或接口定义存在代替功能完成。
