# Android 客户端设备交互设计

本文描述待实现的交互与验收场景。每台设备使用自己的 MusicFS 登录会话和播放队列。界面读取本机播放状态，把操作交给共享播放层。曲库和歌单由 Server 按当前账号授权提供。

## 手机与平板

手机和平板使用同一套页面、导航和界面状态。布局按应用窗口当前可用宽度调整，同时考虑横屏下的可用高度。紧凑窗口依次显示歌单列表、所选歌单的曲目。空间充足时并排显示两者，点选左侧歌单即可更新右侧曲目。在宽屏上也可以通过系统分屏回到单栏。[Android 窗口尺寸类别](https://developer.android.com/develop/adaptive-apps/guides/use-window-size-classes)

列表与详情共用所选歌单标识。旋转或调整窗口后，保留选中项和滚动位置。从双栏收窄时，已打开的歌单详情继续可见，返回可回到对应列表项。底部播放栏、完整播放页和系统媒体控件都反映同一队列与曲目进度。切换页面或改变布局时，播放服务继续持有原会话。

## Android TV

电视从主屏幕打开专用入口，首页优先呈现曲库、歌单和正在播放。封面、曲名和焦点标记需在沙发观看距离清楚可辨。配置 Server 地址和输入登录凭据可以使用方向键、确认键与系统屏幕键盘完成。[创建 Android TV 应用](https://developer.android.com/training/tv/get-started/create)

- **方向键**按屏幕上的空间关系移动焦点。打开歌单时焦点落在首个可操作项。曲目列表滚动、封面加载及播放进度刷新均保留用户焦点。
- **确认键**激活当前选项。播放页为播放／暂停、上一首、下一首提供独立焦点。设备有媒体键时，媒体键也通过本机媒体会话提交对应命令。
- **返回键**先关闭当前弹层，再逐级退回上一个页面。从曲目页返回歌单列表时，恢复到进入前的歌单。离开播放页后，用户仍能从“正在播放”返回当前曲目。

遥控器的基本导航无需触摸、鼠标或专用媒体键。实现时逐屏验证主路径上的焦点可达性和返回顺序。[Android TV 导航指南](https://developer.android.com/training/tv/get-started/navigation)

## Wear OS 独立播放

手表单独安装，清单声明 `android.hardware.type.watch` 和 `com.google.android.wearable.standalone=true`。用户可在手机关机时，从手表完成首次连接、登录、选歌、播放和重新登录。[Wear OS 独立应用](https://developer.android.com/training/wearables/apps/standalone-apps)

1. **连接与登录。** 手表提供可直接输入的 Server 地址和登录凭据字段，由共享连接层校验目标实例并建立手表自己的会话。登录过期后，在表端重新认证。切换实例或退出时清理旧账号状态。
2. **选择曲目。** 小屏使用单列歌单与曲目列表。用户从表端选择曲目后，手表自行建立服务端播放会话，通过 HTTP 读取协商得到的音频流，由表端播放器解码并输出。播放页突出曲名、播放／暂停与切歌，熄屏后由本机播放服务继续播放。
3. **网络变化。** 在线播放需要手表通过 Wi-Fi 或设备具备的蜂窝网络访问 Server。弱网时优先保留音频带宽，封面延后加载。缓冲耗尽后展示等待或重试状态。重新连通时由共享播放层依协议恢复，无法续播时让用户选择是否从头播放。持久下载和离线曲库属于另行设计的能力。
4. **耳机与音箱。** 用户从手表选择蓝牙耳机或音箱。开始播放时若没有合适输出，提示连接设备。播放中输出断开时暂停，重新连接后由用户继续播放，避免音乐突然从表内扬声器播放。[Wear OS 媒体应用指南](https://developer.android.com/media/implement/surfaces/wear-os)

## 设备验收场景

| 设备与条件 | 操作与预期结果 |
| --- | --- |
| 手机竖屏、平板宽屏与分屏 | 打开同一歌单并播放，旋转或拖窄窗口。详情随布局切换，曲目、队列和播放进度连续，返回后仍能找到原歌单。 |
| 仅有方向键、确认和返回的电视遥控器 | 从电视主屏幕启动，完成登录、选歌、播放／暂停、切歌和返回。每一步都能看见焦点，返回歌单后焦点落回原项。 |
| 手机关机、手表清除应用数据并连接可访问 Server 的 Wi-Fi | 仅用手表输入连接信息和凭据，选歌后由连接到手表的耳机出声。熄屏再打开播放页能看到当前进度，退出账号后可在表上重新登录。 |
| 具备蜂窝网络的手表 | 断开手机连接，通过蜂窝网络选歌并播放。切换 Wi-Fi、短时断网再恢复，检查缓冲和恢复状态、曲目及进度。仅局域网可达的 Server 在外网应呈现连接失败。 |
| 正在播放的手表断开蓝牙耳机 | 播放暂停，表内扬声器保持安静。重新连接并点击继续后，耳机恢复输出。 |
| 同一局域网有可发现的 Server | 从登录页的附近服务器列表选择实例，确认填入的地址和端口。退出 Server 后列表移除该实例，手动地址仍可编辑。 |
